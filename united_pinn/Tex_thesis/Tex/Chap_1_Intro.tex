\chapter{引言}\label{chap:intro}

\section{研究背景与意义}\label{sec:background}

期权是金融衍生品市场的核心工具之一，广泛应用于风险对冲、投机和套利。根据国际清算银行（BIS）统计，全球场外衍生品市场名义本金规模超过600万亿美元，其中期权类产品占据重要份额。期权定价的准确性直接影响风险对冲效率、投资组合管理决策和监管资本计算，是金融工程领域的核心问题之一。

自Black、Scholes与Merton于1973年提出BSM模型\cite{black1973pricing,merton1973theory}以来，期权定价理论经历了从常数波动率到局部波动率（CEV模型\cite{cox1976valuation}）、再到随机波动率（Heston模型\cite{heston1993closed}）的演进。这三大模型分别对应不同的市场假设，在实践中各有适用场景：

\begin{itemize}
  \item \textbf{BSM模型}：假设标的资产波动率为常数，具有封闭解析解，计算效率极高，适用于波动率相对平稳的短期定价场景。然而，BSM模型无法解释市场中普遍存在的波动率微笑（volatility smile）现象——即不同执行价的隐含波动率并非常数，而是呈现出"微笑"或"偏斜"形状。
  \item \textbf{CEV模型}：将BSM中的常数波动率推广为依赖于标的价格的局部波动率$\sigma S^{\beta-1}$，能够捕捉股票市场中波动率随股价下跌而上升的杠杆效应（leverage effect），更好地拟合股票期权的波动率偏斜。
  \item \textbf{Heston模型}：通过引入随机波动率过程（CIR过程），更准确地描述波动率微笑和厚尾收益率分布，在外汇期权、指数期权等场景中被广泛使用。Heston模型具有半解析解（通过特征函数方法），但数值求解二维PDE的计算代价显著高于一维情形。
\end{itemize}

然而，传统数值方法（有限差分、有限元）在求解高维PDE时面临"维数灾难"（curse of dimensionality）：网格点数随维度指数增长，Heston这样的二维模型已需要大量计算资源（网格$200\times200\times200$约需500ms），而更高维的随机波动率模型（如多因子Heston）则几乎无法用传统方法实时求解。此外，传统工具要求用户手动指定模型类型和参数，对非专业用户门槛较高——选择合适的定价模型本身就需要量化金融背景，普通用户难以判断在当前市场条件下应使用BSM、CEV还是Heston。

物理信息神经网络（Physics-Informed Neural Networks，PINN）\cite{raissi2019physics}提供了一种新的思路：将PDE残差直接嵌入神经网络的损失函数，无需网格剖分，训练完成后可对任意输入即时推断（单次推断约2ms，远低于有限差分的约500ms）。近年来，PINN已被应用于BSM\cite{dhiman2023pinn}、CEV\cite{bae2024localvol}、Heston\cite{hainaut2024heston,guo2024icpinn}等期权定价模型，展现出良好的精度和效率。

与此同时，大语言模型（Large Language Models，LLM）在自然语言理解和结构化信息提取方面取得了突破性进展。将LLM与科学计算工具结合，使用户能够通过自然语言描述问题并获得计算结果，是人机交互的重要方向\cite{liu2025pdeagent}。在期权定价场景中，LLM的核心价值在于：将"选择合适的定价模型"这一需要专业知识的决策自动化，使非专业用户只需描述期权需求，系统自动完成模型选择和参数提取。

\section{现有工作的局限性}\label{sec:motivation}

综合现有PINN期权定价研究，存在以下主要不足：

\textbf{模型孤立，缺乏统一框架。}现有工作（Dhiman等\cite{dhiman2023pinn}、Bae等\cite{bae2024localvol}、Hainaut等\cite{hainaut2024heston}）均针对单一模型分别训练独立的PINN，三个模型之间无法共享网络权重和训练经验。当需要同时支持多种模型时，必须维护多套独立的训练流程和模型文件，工程复杂度高。更重要的是，独立训练的Heston PINN往往面临严重的收敛困难，因为二维PDE的配点需求远高于一维情形，而独立训练无法从BSM/CEV的简单结构中获益。

\textbf{交互门槛高，缺乏自然语言接口。}现有PINN工具要求用户手动指定模型类型（BSM/CEV/Heston）和所有数值参数，对非专业用户不友好。不同市场条件下应选用何种模型，需要量化金融背景，普通用户难以判断。例如，当用户描述"我想对一个波动率随机变化的股票期权定价"时，传统工具无法理解这一自然语言描述，而需要用户明确指定Heston模型及其所有参数（$\kappa,\theta,\xi,\rho,v_0$）。

\textbf{Heston模型收敛困难。}Heston PDE是二维问题，包含交叉偏导项$\partial^2 V/\partial S\partial v$，独立训练的PINN在Heston上往往收敛困难（本文实验中独立Heston PINN的训练损失停留在$10^3$量级，无法收敛）。这一问题在现有文献中鲜有系统性分析，Hainaut等\cite{hainaut2024heston}虽然成功训练了Heston PINN，但其方法依赖于特殊的网络结构和大量超参数调整，缺乏通用性。

本文针对上述不足，提出将三大模型统一为单一参数化PINN的方法，并结合LLM路由层构建完整的自然语言期权定价系统。

\section{研究目标与贡献}\label{sec:contributions}

本文的研究目标是构建一个基于PINN与LLM的统一期权定价框架，实现以下目标：

\begin{enumerate}
  \item 设计统一PDE算子，通过软掩码机制将BSM、CEV、Heston三大模型的PDE统一为单一参数化形式，由一个网络同时覆盖三种模型；
  \item 采用加法参数化输出，以Black-Scholes解析解为基线，解决深度虚值区域的数值退化问题；
  \item 对Heston模型采用ICPINN硬约束技术，确保终值条件精确满足；
  \item 引入LLM作为智能路由层，支持中英文自然语言输入，自动完成模型选择和参数提取；
  \item 通过与解析解、有限差分参考解的对比，定量评估统一PINN的精度，并与独立PINN基线对比。
\end{enumerate}

本文的主要贡献如下：

\begin{itemize}
  \item \textbf{统一PDE算子设计}：提出软掩码机制$\text{mask}=\tanh(\xi/0.05)^2$，将三大模型的扩散系数统一为$a=(1-\text{mask})\sigma^2 S^{2\beta}+\text{mask}\cdot v S^2$，实现模型间的连续插值，单一网络覆盖三种定价模型。这一设计使得网络在BSM/CEV和Heston之间平滑过渡，避免了硬切换带来的梯度不连续问题。
  \item \textbf{加法参数化输出}：以Black-Scholes解析解$V_\text{BS}$为基线，网络输出$V=V_\text{BS}+K\cdot\text{net}(x)$，解决了乘法参数化在深度虚值区域$V_\text{BS}\to 0$时的退化问题，同时提供良好的初始化（训练开始时$V\approx V_\text{BS}$）。
  \item \textbf{LLM路由集成}：将DeepSeek LLM与统一PINN求解器结合，通过结构化JSON输出实现可靠的参数提取和模型选择，支持中英文自然语言输入，降低期权定价工具的使用门槛。
  \item \textbf{实验验证}：在BSM（MAE=0.067，ATM相对误差0.31\%）和Heston（MAE=0.031，ATM相对误差0.52\%）上验证了统一框架的有效性，并与独立PINN基线进行了对比。特别地，统一框架成功解决了独立Heston PINN完全无法收敛的问题。
  \item \textbf{消融实验}：系统验证了软掩码、加法参数化和数据锚点三个核心组件的必要性，为统一框架的设计选择提供了实验依据。
\end{itemize}

\section{论文结构}\label{sec:structure}

本文其余部分组织如下：

\begin{itemize}
  \item 第二章回顾期权定价模型（BSM、CEV、Heston）的PDE形式、PINN方法的基本原理及其在期权定价中的应用，以及LLM辅助科学计算的最新进展；
  \item 第三章介绍本文提出的统一PINN框架，包括统一PDE算子设计、软掩码机制、加法参数化输出、网络架构、损失函数、训练策略，以及LLM路由层的设计；
  \item 第四章报告实验结果，包括训练过程分析、精度评估、与独立PINN基线的对比、推断速度对比、LLM路由层评估和消融实验；
  \item 第五章总结全文，与现有工作进行比较，并讨论局限性与未来工作方向。
\end{itemize}
