\chapter{方法}\label{chap:method}

本章介绍基于物理信息神经网络（PINN）与大语言模型（LLM）的统一期权定价框架。系统整体流程为：用户以自然语言描述期权需求，LLM路由层解析参数并选择模型，统一PINN求解器返回定价结果。

\section{三大期权定价模型}\label{sec:three_models}

\subsection{模型参数定义}

本文涉及的三大期权定价模型共享以下基础参数：
\begin{itemize}
  \item $S$：标的资产（股票）的当前价格，单位为货币；
  \item $K$：期权执行价（Strike Price），即到期时买入/卖出标的资产的约定价格；
  \item $T$：期权到期时刻，$\tau=T-t$为剩余到期时间；
  \item $r$：无风险利率（连续复利形式），通常取国债收益率；
  \item $V(S,t)$ 或 $V(S,v,t)$：期权价值，是本文求解的目标函数。
\end{itemize}

各模型还引入了刻画波动率结构的专有参数，详见下文各小节。

\subsection{Black-Scholes-Merton（BSM）模型}

\subsubsection{模型假设与应用场景}

BSM模型\cite{black1973pricing,merton1973theory}假设标的资产价格服从几何布朗运动：
\begin{equation}\label{eq:bsm_sde}
  \frac{dS}{S} = \mu\,dt + \sigma\,dW_t,
\end{equation}
其中$\mu$为漂移率，$\sigma>0$为常数波动率，$W_t$为标准布朗运动。

BSM模型的核心假设是波动率$\sigma$为常数，这在以下场景中是合理的近似：
\begin{itemize}
  \item \textbf{蓝筹股短期期权}：对于波动率相对稳定的大盘蓝筹股（如标普500成分股），短期（1个月以内）期权的隐含波动率变化不大，BSM是业界最常用的定价基准；
  \item \textbf{外汇期权}：主要货币对（EUR/USD、USD/JPY等）的波动率在短期内较为平稳，BSM被广泛用于外汇期权的快速定价和对冲比率（Greeks）计算；
  \item \textbf{利率衍生品的近似定价}：在利率期权（如利率上限/下限）的Black模型中，BSM框架被直接应用于远期利率。
\end{itemize}

BSM模型的专有参数为$\sigma$（常数波动率），其典型取值范围为$0.1$至$0.5$（即年化波动率10\%至50\%）。

\subsubsection{BSM偏微分方程}

在风险中性测度下，欧式看涨期权价值$V(S,t)$满足BSM偏微分方程：
\begin{equation}\label{eq:bsm_pde}
  \frac{\partial V}{\partial t} + \frac{1}{2}\sigma^2 S^2 \frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0,
\end{equation}
终值条件为$V(S,T)=\max(S-K,0)$，边界条件为$V(0,t)=0$，$V(S,t)\to S-Ke^{-r(T-t)}$（$S\to\infty$）。

BSM方程存在解析解（Black-Scholes公式）：
\begin{align}
  V_\text{BS}(S,\tau;\sigma) &= S\Phi(d_1) - Ke^{-r\tau}\Phi(d_2), \label{eq:bs_formula}\\
  d_1 &= \frac{\ln(S/K)+(r+\sigma^2/2)\tau}{\sigma\sqrt{\tau}}, \quad d_2 = d_1 - \sigma\sqrt{\tau},
\end{align}
其中$\Phi(\cdot)$为标准正态累积分布函数，$\tau=T-t$。本文将此解析解作为加法参数化的基线（见第~\ref{sec:additive_param}节）。

\subsection{常弹性方差（CEV）模型}

\subsubsection{模型假设与应用场景}

CEV模型\cite{cox1976valuation}将BSM的常数波动率推广为股价的幂函数：
\begin{equation}\label{eq:cev_sde}
  \frac{dS}{S} = \mu\,dt + \sigma S^{\beta-1}\,dW_t,
\end{equation}
即瞬时波动率为$\sigma S^{\beta-1}$，随股价变化而变化。参数$\beta$（弹性参数）控制波动率对股价的依赖程度：
\begin{itemize}
  \item $\beta=1$：退化为BSM（常数波动率）；
  \item $\beta<1$：波动率随股价下跌而上升，产生"杠杆效应"（Leverage Effect），符合股票市场的实证规律；
  \item $\beta>1$：波动率随股价上升而上升，适用于某些商品市场。
\end{itemize}

CEV模型适用于以下场景：
\begin{itemize}
  \item \textbf{股票期权（杠杆效应显著）}：实证研究表明，股票价格下跌时波动率往往上升（负相关），CEV模型（$\beta<1$）能够捕捉这一特征，在个股期权定价中优于BSM；
  \item \textbf{利率衍生品}：在利率模型中，CEV过程（$\beta=0.5$，即CIR过程）被用于建模短期利率，对应的期权定价也采用CEV框架；
  \item \textbf{商品期权}：能源、农产品等商品的波动率与价格正相关（$\beta>1$），CEV模型能更好地拟合商品期权的隐含波动率曲面。
\end{itemize}

CEV模型的专有参数为$\beta$（弹性参数），本文取$\beta=0.5$，对应中等强度的杠杆效应。

\subsubsection{CEV偏微分方程}

CEV模型下欧式看涨期权满足：
\begin{equation}\label{eq:cev_pde}
  \frac{\partial V}{\partial t} + \frac{1}{2}\sigma^2 S^{2\beta} \frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0.
\end{equation}
与BSM方程相比，扩散系数由$\sigma^2 S^2$变为$\sigma^2 S^{2\beta}$。CEV方程无封闭解析解（$\beta\neq 1$时），通常用有限差分法或级数展开法求解。

\subsection{Heston随机波动率模型}

\subsubsection{模型假设与应用场景}

Heston模型\cite{heston1993closed}引入随机波动率，用二维随机微分方程组描述股价与方差的联合动态：
\begin{align}
  dS &= \mu S\,dt + \sqrt{v}\,S\,dW_t^S, \label{eq:heston_sde_s}\\
  dv &= \kappa(\theta - v)\,dt + \xi\sqrt{v}\,dW_t^v, \label{eq:heston_sde_v}\\
  dW_t^S\,dW_t^v &= \rho\,dt. \label{eq:heston_corr}
\end{align}
各参数的物理含义如下：
\begin{itemize}
  \item $v$：瞬时方差（即波动率的平方），是随机变量；
  \item $\kappa>0$：方差过程的均值回归速度，$\kappa$越大，方差越快回归长期均值；
  \item $\theta>0$：方差过程的长期均值（长期方差），$\sqrt{\theta}$为长期波动率；
  \item $\xi>0$：方差过程的波动率（vol-of-vol），刻画波动率本身的随机性强度；
  \item $\rho\in(-1,1)$：股价布朗运动$W_t^S$与方差布朗运动$W_t^v$的相关系数，通常为负值（股价下跌时波动率上升）；
  \item $v_0$：初始瞬时方差。
\end{itemize}

方差过程~\eqref{eq:heston_sde_v}为CIR（Cox-Ingersoll-Ross）过程，当Feller条件$2\kappa\theta\geq\xi^2$满足时，方差过程严格为正。

Heston模型适用于以下场景：
\begin{itemize}
  \item \textbf{指数期权（波动率微笑/偏斜）}：标普500等指数期权的隐含波动率曲面呈现显著的"波动率偏斜"（Volatility Skew），Heston模型通过负相关系数$\rho<0$和随机波动率$\xi>0$能够拟合这一特征，是指数期权定价的行业标准模型之一；
  \item \textbf{长期期权}：对于到期时间超过6个月的期权，波动率的随机性不可忽略，Heston模型比BSM更准确；
  \item \textbf{波动率衍生品}：VIX期权、方差互换等以波动率为标的的衍生品，需要对波动率过程本身建模，Heston框架是自然选择；
  \item \textbf{美股市场期权}：纽约证券交易所（NYSE）和纳斯达克（NASDAQ）上市的股票期权，尤其是科技股期权（如AAPL、TSLA），波动率随机性强，Heston模型被广泛应用于做市商的定价系统。
\end{itemize}

\subsubsection{Heston偏微分方程}

在风险中性测度下，Heston模型下欧式看涨期权满足二维PDE：
\begin{equation}\label{eq:heston_pde}
  \frac{\partial V}{\partial t}
  + \frac{1}{2}vS^2\frac{\partial^2 V}{\partial S^2}
  + \rho\xi vS\frac{\partial^2 V}{\partial S\partial v}
  + \frac{1}{2}\xi^2 v\frac{\partial^2 V}{\partial v^2}
  + rS\frac{\partial V}{\partial S}
  + \kappa(\theta-v)\frac{\partial V}{\partial v}
  - rV = 0.
\end{equation}
与BSM/CEV相比，Heston PDE新增了交叉偏导项$\rho\xi vS\cdot\partial^2 V/\partial S\partial v$和$v$方向的扩散项$\frac{1}{2}\xi^2 v\cdot\partial^2 V/\partial v^2$，使问题从一维升至二维，求解难度显著增加。Heston模型存在半解析解（特征函数方法），但数值实现较复杂；本文将其作为数据锚点的参考解。

\subsection{本文的适用范围：美股市场欧式期权}

\subsubsection{LLM适配美股欧式期权}

本文的LLM路由层和统一PINN框架针对\textbf{美股市场的欧式看涨/看跌期权}设计，原因如下：

\textbf{（1）欧式期权的PDE框架完备。}欧式期权在到期日才能行权，其定价满足确定的终值问题（PDE+终值条件+边界条件），PINN可以直接求解。美式期权涉及提前行权的自由边界问题，PDE结构不同，需要额外处理最优停止问题，超出本文框架范围（见第~\ref{sec:limitations}节）。

\textbf{（2）美股期权市场数据充分，参数可校准。}芝加哥期权交易所（CBOE）提供标准化的美股期权数据，BSM、CEV、Heston三大模型的参数（$\sigma$、$\beta$、$\kappa$、$\theta$、$\xi$、$\rho$）均可通过隐含波动率校准方法从市场数据中提取。本文实验使用的参数范围（$\sigma\in[0.1,0.5]$，$\kappa\in[1,5]$，$\xi\in[0.1,0.5]$，$\rho\in[-0.9,-0.3]$）与美股市场的实证参数范围吻合。

\textbf{（3）LLM支持英文金融术语。}美股期权的描述通常使用英文金融术语（"European call"、"stochastic volatility"、"vol-of-vol"等），本文的LLM路由层（基于DeepSeek API）对英文输入的理解能力强，能够准确识别这些术语并映射到对应的模型参数。

\subsubsection{未引入A股市场的原因}

本文未将A股市场（上海证券交易所、深圳证券交易所）的期权数据纳入框架，主要原因如下：

\textbf{（1）参数不匹配。}A股市场的期权品种主要为上证50ETF期权和沪深300ETF期权，其隐含波动率特征与美股有显著差异：A股波动率通常更高（年化波动率常超过30\%），且受政策因素影响，波动率的均值回归速度$\kappa$和长期均值$\theta$与美股参数范围不同。若直接使用本文训练的统一PINN（参数范围针对美股校准）对A股期权定价，会产生系统性偏差。

\textbf{（2）数据接口差异。}AkShare等A股数据接口提供的期权数据格式（合约代码、到期日编码、行权价格单位等）与本文LLM路由层的参数提取逻辑不兼容，需要额外的数据预处理和格式转换模块，超出本文的工程范围。

\textbf{（3）市场微结构差异。}A股期权市场存在涨跌停限制、T+1交割等特殊规则，这些规则会影响期权的实际定价，但在标准BSM/CEV/Heston框架中无法直接建模。

\subsubsection{未涉及其他期权类型的原因}

本文仅针对欧式看涨/看跌期权，未涉及以下期权类型：

\textbf{（1）美式期权。}美式期权允许在到期前任意时刻行权，其定价等价于一个最优停止问题，对应的PDE为变分不等式（而非等式），需要处理自由边界（最优行权边界）。这与本文的统一PDE算子框架（等式约束）不兼容，需要引入惩罚函数法或互补条件，显著增加求解复杂度。

\textbf{（2）障碍期权（Barrier Options）。}障碍期权在标的资产价格触及某一障碍价格时自动失效或激活，其定价PDE与欧式期权相同，但边界条件不同（在障碍处$V=0$或$V=\text{回扣}$）。虽然理论上可以纳入本文框架，但障碍期权的边界条件处理需要额外的网络设计，留作未来工作。

\textbf{（3）亚式期权（Asian Options）。}亚式期权的收益依赖于标的资产在整个存续期内的平均价格，其定价PDE引入了路径依赖变量（累积平均价格），维度更高，超出本文的二维PDE框架。

\section{统一PDE算子}\label{sec:unified_pde}

\subsection{三大模型的PDE统一形式}

BSM、CEV、Heston三大模型的PDE在形式上具有高度相似性，均可写为如下统一算子：
\begin{equation}\label{eq:unified_pde}
  \mathcal{F}[V] =
    \frac{\partial V}{\partial t}
    + \frac{1}{2}a(S,v;\boldsymbol{\lambda})\frac{\partial^2 V}{\partial S^2}
    + b(S,v;\boldsymbol{\lambda})\frac{\partial^2 V}{\partial S\partial v}
    + \frac{1}{2}c(v;\boldsymbol{\lambda})\frac{\partial^2 V}{\partial v^2}
    + rS\frac{\partial V}{\partial S}
    + d(v;\boldsymbol{\lambda})\frac{\partial V}{\partial v}
    - rV = 0,
\end{equation}
其中参数向量$\boldsymbol{\lambda}=(\sigma,\beta,\kappa,\theta,\xi,\rho)$控制各系数，具体对应关系如表~\ref{tab:unified_coefficients}所示。

\begin{table}[htbp]
  \centering
  \caption{统一PDE算子系数与三大模型的对应关系}
  \label{tab:unified_coefficients}
  \begin{tabular}{lcccc}
    \hline
    模型 & $a(S,v;\boldsymbol{\lambda})$ & $b(S,v;\boldsymbol{\lambda})$ & $c(v;\boldsymbol{\lambda})$ & $d(v;\boldsymbol{\lambda})$ \\
    \hline
    BSM & $\sigma^2 S^2$ & $0$ & $0$ & $0$ \\
    CEV & $\sigma^2 S^{2\beta}$ & $0$ & $0$ & $0$ \\
    Heston & $vS^2$ & $\rho\xi vS$ & $\xi^2 v$ & $\kappa(\theta-v)$ \\
    \hline
  \end{tabular}
\end{table}

当$\xi=0$时，$b=c=d=0$，统一算子自动退化为一维BSM/CEV方程；当$\xi>0$时，交叉项和$v$方向扩散项被激活，对应Heston的二维随机波动率结构。

\subsection{软掩码机制}

为实现三大模型之间的连续插值，本文引入软掩码（Soft Mask）：
\begin{equation}\label{eq:soft_mask}
  \text{mask} = \tanh\!\left(\frac{\xi}{0.05}\right)^2.
\end{equation}
当$\xi\to 0$时，$\text{mask}\to 0$；当$\xi$较大（如$\xi=0.3$）时，$\text{mask}\approx 1$。利用软掩码，扩散系数$a$统一为：
\begin{equation}\label{eq:soft_a}
  a = (1-\text{mask})\cdot\sigma^2 S^{2\beta} + \text{mask}\cdot v S^2.
\end{equation}
这一设计使得：
\begin{itemize}
  \item 当$\xi=0$（BSM/CEV）时，$a=\sigma^2 S^{2\beta}$，精确退化为BSM/CEV扩散项；
  \item 当$\xi=0.3$（Heston）时，$\text{mask}\approx 0.998$，$a\approx vS^2$，精确对应Heston扩散项；
  \item 中间状态时，$a$在两者之间连续插值，网络可以学习到平滑的参数依赖关系。
\end{itemize}

软掩码的阈值$0.05$是根据实验调整的超参数：过小会导致BSM/CEV区域的梯度消失，过大会使Heston区域的掩码不够接近1。

\section{加法参数化输出}\label{sec:additive_param}

\subsection{设计动机}

直接用神经网络输出期权价格存在两个问题：
\begin{enumerate}
  \item \textbf{初始化困难}：期权价格量级约为$10^0$至$10^2$，随机初始化的网络输出量级约为$10^{-1}$，训练初期梯度信号弱；
  \item \textbf{深度虚值退化}：当$S\ll K$时，期权价格趋近于0，乘法参数化$V=V_\text{BS}\cdot(1+\text{net})$在$V_\text{BS}\to 0$时退化，网络无法学习到有效的修正量。
\end{enumerate}

\subsection{加法参数化}

本文采用加法参数化输出：
\begin{equation}\label{eq:additive}
  \hat{V}(S,v,t;\boldsymbol{\lambda}) = V_\text{BS}(S,\tau;\sigma_\text{eff}) + K\cdot\text{net}(x),
\end{equation}
其中$\tau=T-t$为剩余时间，$\sigma_\text{eff}$为等效波动率，$\text{net}(x)$为神经网络输出的修正量（以$K$为单位，量级约为$0$至$0.1$）。

等效波动率$\sigma_\text{eff}$通过软掩码计算：
\begin{equation}\label{eq:sigma_eff}
  \sigma_\text{eff} = (1-\text{mask})\cdot\sigma + \text{mask}\cdot\sqrt{v}.
\end{equation}
即BSM/CEV时用常数波动率$\sigma$，Heston时用当前方差$v$的平方根作为近似波动率。

加法参数化的优势：
\begin{itemize}
  \item \textbf{良好初始化}：网络最后一层权重初始化为$\mathcal{N}(0, 0.001^2)$，使训练开始时$K\cdot\text{net}\approx 0.1\ll V_\text{BS}\approx 10$，网络从接近正确答案的位置开始优化；
  \item \textbf{解决OTM退化}：深度虚值时$V_\text{BS}\to 0$，但$K\cdot\text{net}$仍可输出非零修正，网络可以学习到CEV/Heston相对于BSM的价格差异；
  \item \textbf{物理意义清晰}：对BSM，$\text{net}\to 0$（BSM解析解已精确）；对CEV，$\text{net}$学习弹性指数修正；对Heston，$\text{net}$学习随机波动率修正。
\end{itemize}

\section{网络架构}\label{sec:architecture}

\subsection{输入特征}

网络输入为9维向量，包含归一化的状态变量和模型参数：
\begin{equation}
  x = \left[\frac{S}{S_\text{max}},\; \frac{v}{v_\text{max}},\; \frac{t}{T},\; \sigma,\; \beta,\; \kappa,\; \theta,\; \xi,\; \rho\right],
\end{equation}
其中$S_\text{max}=300$，$v_\text{max}=1$。归一化使各输入均落在$[0,1]$区间，避免不同量级的输入导致梯度不平衡。

\subsection{网络结构}

网络采用6层全连接结构，每层128个神经元，激活函数为$\tanh$：
\begin{align}
  h_0 &= x \in \mathbb{R}^9, \\
  h_l &= \tanh(W_l h_{l-1} + b_l), \quad l=1,\ldots,6, \\
  \text{net}(x) &= W_7 h_6 + b_7 \in \mathbb{R}.
\end{align}
最后一层权重初始化为$\mathcal{N}(0, 0.001^2)$，偏置初始化为0，确保训练开始时$\text{net}\approx 0$。

$\tanh$激活函数的选择基于以下考虑：（1）$\tanh$是光滑函数，其高阶导数存在且有界，适合PINN中需要计算二阶偏导数的场景；（2）$\tanh$的输出范围$(-1,1)$有助于控制网络输出的量级；（3）相比ReLU，$\tanh$在原点附近的梯度更大，有助于训练初期的快速收敛。

\subsection{硬约束终值条件（ICPINN）}

软约束方式将终值条件纳入损失函数，网络只能近似满足。参考Guo等人\cite{guo2024icpinn}的ICPINN方法，本文通过输出变换将终值条件硬编码。当$t=T$时，$\tau=T-t=0$，Black-Scholes公式自动退化为终值条件$V_\text{BS}(S,0;\sigma_\text{eff})=\max(S-K,0)$；同时，网络最后一层的小初始化确保修正量$K\cdot\text{net}$在训练初期接近0，不破坏终值条件的满足。

\section{损失函数}\label{sec:loss}

\subsection{复合损失}

统一PINN的总损失由三部分组成：
\begin{equation}\label{eq:total_loss}
  \mathcal{L}(\theta) = w_\text{pde}\,\mathcal{L}_\text{pde}
                      + w_\text{bc}\,\mathcal{L}_\text{bc}
                      + w_\text{data}\,\mathcal{L}_\text{data},
\end{equation}
其中各项定义如下。

\subsection{PDE残差损失}

在求解域$\Omega\times[0,T)$内随机采样$N_c$个配点$\{(S_i,v_i,t_i)\}$，计算统一PDE算子的残差：
\begin{equation}
  \mathcal{L}_\text{pde} = \frac{1}{N_c}\sum_{i=1}^{N_c}
    \left(\frac{\mathcal{F}[\hat{V}](S_i,v_i,t_i)}{|\hat{V}(S_i,v_i,t_i)|+1}\right)^2.
\end{equation}
分母中的$|\hat{V}|+1$为相对残差归一化项，避免ATM区域（$V\approx 10$）的残差主导损失，使OTM区域（$V\approx 0.1$）也能获得足够的梯度信号。

\subsection{边界条件损失}

边界条件设置为：
\begin{align}
  V(0,v,t) &= 0, \label{eq:bc_lower} \\
  V(S_\text{max},v,t) &= S_\text{max} - Ke^{-r(T-t)}, \label{eq:bc_upper} \\
  V(S,v_\text{max},t) &\approx S. \label{eq:bc_vmax}
\end{align}
式~\eqref{eq:bc_lower}表示股价为0时期权价值为0；式~\eqref{eq:bc_upper}为深度实值近似；式~\eqref{eq:bc_vmax}表示极高波动率下期权价值趋近于标的资产价格。

边界条件损失为：
\begin{equation}
  \mathcal{L}_\text{bc} = \frac{1}{N_b}\sum_{k=1}^{N_b}
    \left|\hat{V}(S_k,v_k,t_k) - g(S_k,v_k,t_k)\right|^2,
\end{equation}
其中$g$为对应边界的目标值。

\subsection{数据驱动锚点损失}

纯PDE约束存在解不唯一的数值问题。本文在$t=0$处预计算参考解（BSM用解析解，CEV用Crank-Nicolson有限差分，Heston用特征函数半解析解），作为数据驱动锚点：
\begin{equation}
  \mathcal{L}_\text{data} = \frac{1}{N_d}\sum_{j=1}^{N_d}
    \left(\hat{V}(S_j,v_j,0) - V_j^*\right)^2,
\end{equation}
其中$V_j^*$为参考解，$N_d=20$（每个模型各20个点）。数据锚点的权重$w_\text{data}=100$远大于PDE权重$w_\text{pde}=1$，确保网络在$t=0$处的精度。

\subsection{损失权重的选择依据}

三个损失项的权重$(w_\text{pde}, w_\text{bc}, w_\text{data})$的选择对训练稳定性和最终精度有重要影响，本文通过以下分析确定权重：

\textbf{量级分析。}PDE残差$\mathcal{L}_\text{pde}$的典型量级为$10^{-2}$至$10^{-1}$（经相对归一化后），边界条件损失$\mathcal{L}_\text{bc}$的典型量级为$10^{-1}$至$10^0$，数据锚点损失$\mathcal{L}_\text{data}$的典型量级为$10^{-2}$至$10^{-1}$。若三者权重相等，数据锚点损失会被边界条件损失主导，导致$t=0$处精度不足。

\textbf{权重设置。}本文设置$w_\text{pde}=1$，$w_\text{bc}=10$，$w_\text{data}=100$。其中：
\begin{itemize}
  \item $w_\text{data}=100$：数据锚点提供了精确的参考解，是最可靠的监督信号，高权重确保网络在已知解处精确拟合，防止PDE约束将解推向错误方向；
  \item $w_\text{bc}=10$：边界条件是PDE适定性的必要条件，中等权重确保边界处的物理约束被满足，同时不过度压制内部PDE残差；
  \item $w_\text{pde}=1$：PDE残差是软约束，权重过大会导致训练初期梯度爆炸（因为初始网络的PDE残差很大），权重为1是稳定训练的基准。
\end{itemize}

\textbf{消融实验验证。}在预实验中，我们测试了$(1,1,1)$、$(1,10,10)$、$(1,10,100)$三组权重，发现$(1,10,100)$在BSM和Heston上均取得最低的ATM相对误差，因此采用此权重组合。

\section{训练策略}\label{sec:training}

\subsection{混合采样}

训练时从三个模型的参数分布中混合采样配点：每个训练步骤中，从BSM、CEV、Heston三个模型各采样$N_c/3$个配点，拼接后计算统一PDE残差。这一策略确保网络在三种模型的参数空间中均匀训练，避免某一模型主导损失。

\subsection{优化器与学习率}

使用Adam优化器\cite{kingma2014adam}，初始学习率$10^{-3}$，每5000步衰减至0.5倍（StepLR调度）。总训练轮数20000轮，在NVIDIA GPU上约需30分钟。

\subsection{配点采样策略}

配点在求解域内均匀随机采样：
\begin{itemize}
  \item BSM/CEV：$S\in[0, S_\text{max}]$，$t\in[0,T]$，$v$固定为$v_0$（一维问题）；
  \item Heston：$S\in[0, S_\text{max}]$，$v\in[0, v_\text{max}]$，$t\in[0,T]$（二维问题）。
\end{itemize}
每个训练步骤重新采样配点（online sampling），避免过拟合到固定配点集。

\section{LLM路由层}\label{sec:llm_router}

\subsection{设计动机}

三种PINN模型分别适用于不同的市场假设：BSM适用于波动率平稳的市场，CEV适用于存在杠杆效应的股票市场，Heston适用于波动率本身随机变化的场景。传统工具要求用户手动指定模型类型和参数，门槛较高。

本文引入LLM作为智能路由层，使用户可以通过自然语言描述期权需求，由LLM自动完成模型选择和参数提取。相比基于规则的解析器，LLM能够处理模糊表达（如"波动率大约20\%"、"存在杠杆效应"）和多语言输入，鲁棒性更强。

\subsection{提示词工程}

LLM路由层的核心是系统提示词（System Prompt）的设计。本文的系统提示词包含以下要素：

\textbf{（1）角色定义。}明确LLM的角色为"期权定价参数提取器"，要求其从用户输入中提取结构化参数，而非进行对话或解释。

\textbf{（2）模型选择规则。}系统提示词中明确规定了三种模型的选择条件：
\begin{itemize}
  \item 若用户仅提供常数波动率$\sigma$，选择\texttt{"bsm"}；
  \item 若用户提及弹性参数$\beta$或"CEV"/"constant elasticity"，选择\texttt{"cev"}；
  \item 若用户提供随机波动率参数（$\kappa,\theta,\xi,\rho,v_0$）或提及"Heston"/"stochastic volatility"，选择\texttt{"heston"}；
  \item 默认选择\texttt{"bsm"}。
\end{itemize}

\textbf{（3）参数默认值。}对用户未提及的参数，系统提示词规定使用以下默认值：$S=100$，$K=100$，$T=1.0$，$r=0.05$，$\sigma=0.2$，$\beta=0.5$，$v_0=0.04$，$\kappa=2.0$，$\theta=0.04$，$\xi=0.3$，$\rho=-0.7$。这些默认值对应美股市场的典型参数范围。

\textbf{（4）输出格式约束。}通过API的\texttt{response\_format: \{type: "json\_object"\}}参数强制LLM输出合法JSON，避免自然语言混入结构化输出。

\subsection{JSON输出Schema}

LLM的输出遵循以下JSON Schema：
\begin{verbatim}
{
  "model": "bsm" | "cev" | "heston",
  "option_type": "call" | "put",
  "S": float,      // 当前股价
  "K": float,      // 执行价
  "T": float,      // 到期时间（年）
  "r": float,      // 无风险利率
  "sigma": float,  // BSM/CEV波动率参数
  "beta": float,   // CEV弹性参数（仅CEV）
  "v0": float,     // 初始方差（仅Heston）
  "kappa": float,  // 均值回归速度（仅Heston）
  "theta": float,  // 长期方差（仅Heston）
  "xi": float,     // vol-of-vol（仅Heston）
  "rho": float     // 相关系数（仅Heston）
}
\end{verbatim}

系统在接收到JSON输出后，进行参数范围校验（如$\sigma>0$，$\beta\in(0,1]$，$\xi>0$，$\rho\in(-1,1)$），对越界参数截断至合法范围，再传入统一PINN求解器。

\subsection{路由规则}

LLM根据以下规则选择模型：
\begin{itemize}
  \item 若用户仅提供常数波动率$\sigma$，选择\textbf{BSM}；
  \item 若用户提及弹性参数$\beta$或"CEV"，选择\textbf{CEV}；
  \item 若用户提供随机波动率参数（$\kappa,\theta,\xi,\rho,v_0$）或提及"Heston"，选择\textbf{Heston}；
  \item 默认选择\textbf{BSM}。
\end{itemize}

\subsection{参数提取与系统流程}

LLM接收用户的自然语言输入，通过\texttt{response\_format: json\_object}约束输出格式，输出结构化JSON参数，包含模型类型、期权类型和所有定价参数。系统提示明确规定了参数格式和默认值，对缺失参数使用合理默认值（$\sigma=0.2$，$\beta=0.5$，$v_0=0.04$，$\kappa=2.0$，$\theta=0.04$，$\xi=0.3$，$\rho=-0.7$）。

完整的定价流程如下：
\begin{enumerate}
  \item 用户输入自然语言描述（中文或英文均可）；
  \item LLM解析输入，提取期权参数，选择定价模型；
  \item 统一PINN加载预训练权重，根据提取的参数构造$\boldsymbol{\lambda}$向量；
  \item 网络前向传播，返回期权价格（约2ms）；
  \item 系统返回期权价格及所用模型信息。
\end{enumerate}

\subsection{本框架的局限性}\label{sec:limitations}

本文框架存在以下局限性，留作未来工作：
\begin{itemize}
  \item \textbf{仅支持欧式期权}：美式期权的自由边界问题需要额外的变分不等式求解器；
  \item \textbf{仅支持美股参数范围}：A股市场的参数分布与本文训练范围不匹配，需重新校准；
  \item \textbf{CEV参考解精度}：CEV模型的有限差分参考解在深度虚值区域存在数值误差，影响数据锚点质量（详见第~\ref{sec:cev_error}节）；
  \item \textbf{LLM依赖外部API}：当前实现依赖DeepSeek API，离线场景需替换为本地部署的LLM。
\end{itemize}

\section{本章小结}\label{sec:method_summary}

本章介绍了基于PINN与LLM的统一期权定价框架。核心创新在于：（1）软掩码机制将三大模型的PDE算子统一为单一参数化形式；（2）加法参数化输出以Black-Scholes解析解为基线，解决了深度虚值区域的数值退化问题；（3）ICPINN硬约束确保终值条件精确满足；（4）LLM路由层通过结构化输出实现可靠的参数提取和模型选择。下一章将报告实验结果。
